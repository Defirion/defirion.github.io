homestack-backups

homestack-backups is a private, single-user tool run by Karim Romani. It is not offered to the public.

It backs up a home server to Karim's own Google Drive. The server runs Backrest, which uses restic to encrypt the backups on the server and rclone to upload them. Google Drive only ever receives encrypted files.

The tool asks Google for the narrowest Drive permission, drive.file. With it, the tool can only see and change the files and folders it created itself. It cannot see anything else in the Drive.
